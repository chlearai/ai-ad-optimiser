Bhago Sakha

Bhago Sakha helps the authorised Bhago Mobility operations team prepare lead-calling and payment-reminder campaigns from its selected Google Sheets.

The Google connection reads the saved source sheets, prepares calling CSV files for Samvaad, and writes approved call outcomes back into the corresponding original rows. Read-only Drive file metadata is used to check editing permission before a source is called. The program restricts updates to saved Bhago source and test files.

Lead calling uses the rider's name, phone number and city or area. Payment reminders also use vehicle number and outstanding amount. Source dates support the selected calling period.

Access is configured for the approved operations account. This page does not provide public registration or access to rider records.
