Installation Guides by Platform

  1. Navigate to your WordPress Admin dashboard → Elementor → Custom Code (or install the free WPCode / Header & Footer Scripts plugin).

  3. Set Location to <head> or <body> - End with Priority 1.
  4. Paste the AdGuard <script> tag snippet above and click Publish (Entire Site or Landing Pages).
  5. All forms (Elementor Forms, Gravity Forms, WPForms, Contact Form 7) are now automatically intercepted!
  1. Open your Google Tag Manager (GTM) container.
  2. Click Tags → New → Tag Configuration → Choose Custom HTML Tag.
  3. Paste the AdGuard <script> code snippet into the HTML box.
  4. Under Triggering, select All Pages (Page View) or your specific Landing Page triggers.
  5. Click Save and Submit / Publish your container. AdGuard begins real-time telemetry instantly.
  1. Webflow: Open Project Settings → Custom Code → Paste into the Head Code or Footer Code box → Click Save & Publish.
  2. Shopify: Go to Online Store → Themes → Edit Code → Open theme.liquid → Paste right before </head> → Save.
  3. Unbounce / Leadpages: Open the landing page builder → Javascripts → Add New → Placement: Before Body End Tag → Paste snippet → Save.
  1. HTML / PHP: Paste the <script async src="..."></script> tag into your base template inside <head> or before </body>.
